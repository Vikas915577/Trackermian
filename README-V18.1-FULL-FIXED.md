# Winter Arc Tracker V18.1 — FULL FIXED PACKAGE

This package keeps the full V18/V17 data engine and legacy feature pages, while replacing the broken V18 mobile shell with a V18.1 UX shell.

## Fixed
- Week habit board: compact 7-day horizontal row; no vertical Friday→Thursday stack or oversized check block.
- Today: YOUR NEXT WIN + one-tap complete/undo + automatic next action.
- Daily priority: MUST DO / SHOULD DO / BONUS.
- Recovery: “No reset needed. Start again with the smallest version.”
- Onboarding: Welcome → Name → What do you want to improve? → Habits → Ready.
- Goals: Fitness / Mind / Work / Overall.
- Habit setup: up to 6 habits.
- Hamburger: real navigation drawer.
- Main access: Today / Week / Profile / More, with direct Month + Arc in More and Arc in the drawer.
- More grouping: YOUR PROGRESS / TOOLS / APP.
- Existing advanced tools remain available through the legacy feature panels: goals, routines, planner, mood/energy, sleep, journal, reminders, privacy, settings, backup/restore/CSV and community.
- PWA install flow with browser fallback. No APK/release CTA is exposed.
- PWA URL shortcuts for Today / Week / Month / Arc / Profile.
- Existing progress_tracker_v17 and older storage keys remain the migration source.
- Winter Arc is fixed to 1 Oct 2026 → 31 Dec 2026 (92 days).
- Community counter does not auto-fetch unless Community Sync is enabled or the user explicitly refreshes it.
