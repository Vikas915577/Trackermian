WINTER ARC V17 PACKAGE

This package contains the V17 app.js plus the backend/dashboard files and image assets that were provided in the chat.

IMPORTANT:
- Replace the existing app.js in your GitHub repo with this package's app.js.
- app-v16-backup.js is the previous uploaded app.js backup.
- Keep your existing index.html, styles/assets, manifest, service worker, etc. in the GitHub repo if they are not included here.
- cloud-config.js must contain only the public Supabase anon key; never put a service-role key in GitHub Pages.
